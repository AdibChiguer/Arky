# Security policy

## Reporting a vulnerability

Please do not open a public issue for a suspected security vulnerability.

Use GitHub's private vulnerability reporting or contact the repository owner privately with:

- A short description of the issue
- Steps to reproduce it
- The affected platform and version
- Any suggested mitigation

Do not include passwords, API keys, private clipboard contents, or other sensitive data in a report.

## Scope

Issues involving local data exposure, unsafe action execution, privilege escalation, or supply-chain and release integrity are especially important to report.
